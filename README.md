# Itzfizz – Scroll-Driven Hero Animation

Next.js (React) + Tailwind CSS + GSAP/ScrollTrigger.

- Intro: staggered headline + stats reveal on load
- Scroll: pinned hero, car position/scale/wheel rotation scrubbed to scroll progress (transform-only)

## Run
npm install && npm run dev

## Deploy (GitHub Pages)
Push to `main`, then Settings → Pages → Source: GitHub Actions.
